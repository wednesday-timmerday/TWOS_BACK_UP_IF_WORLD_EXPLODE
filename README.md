## TWOS
A game made by a lot of people

## Run Locally  

Clone the project  

~~~bash  
  git clone https://dormoticz.duckdns.org:8030/TWOS/TWOS
~~~

Go to the project directory  

~~~bash  
  cd TWOS
~~~

Install dependencies  

~~~bash  
pip install pygame numpy pillow pypresence pydub requests keyboard pyautogui
~~~

Start the game

~~~bash  
python main.py
~~~
